| 2 | VISTA/Tycho/Schema/AVO 公开集满分只证明 Harness 工程的杠杆作用，**不构成**私有任务泛化或商业价值证明 | §1：限定"在公开基准上""Harness 工程""尚无产品把它做进企业可用的平台层"；SM-C4 明确"公开基准分数不得成为目标"。但 PRD 写"**数倍**杠杆"，而边界仅承认"杠杆作用"，量化词无边界或来源支撑 | 基本一致，存在轻微加满，见差距 G2 |

## 三、差距与建议

- **G1（未承接）**：附录 §8-6"简报口径（内部对齐 vs 融资叙事）"未进入 PRD §12，也无任何下放记录。该问题虽属简报文档自身治理，但按"全部进入 PRD §12 或有意识下放"的验收标准构成缺口。
  建议：在 PRD §12 增补一条，或在 §0 上游输入说明中显式声明"简报口径问题归属简报文档层面，不在 PRD 开放问题范围"。
- **G2（口径加满）**：PRD §1"已在公开基准上证明……Harness 工程具有**数倍**杠杆"——边界 §1-2 仅承认"杠杆作用"，"数倍"是边界未授权的量化强化且无 [ASSUMPTION] 标注或来源引用。
  建议：改为"显著杠杆/可测量的杠杆"，或保留量化但内联 [ASSUMPTION] 并入 §13 假设索引。
- **G3（上下文丢失）**：附录 §8-2 附带的默认开源建议（协议/SDK/本地运行/基础回放开放）未随开放问题带入 PRD §12-2。开放问题本身承接了，但决策时赖以起步的默认方案在 PRD 层丢失。
  建议：在 §12-2 括注"（附录默认建议：协议/SDK/本地运行/基础回放开放）"。

轻微观察（不计入差距，供 PM 参考）：

- 商标核查时点存在三处表述（附录边界"公测前"、附录 §8-5 与 PRD §12-5"Developer Preview 前"），PRD 取最严者，可接受；建议后续文档统一引用同一时点。
- PRD §1"研究成熟度与产品空白的窗口期"为愿景修辞，结合同段"尚无产品……"限定，未越界；保持定性即可，勿在下游再放大。
